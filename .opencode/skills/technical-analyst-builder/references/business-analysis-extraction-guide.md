# Business Analysis Extraction Guide

When reading a business analysis, extract the implementation intent.

## Extract

- epic;
- business context;
- core business rule;
- user stories;
- acceptance criteria;
- actors;
- input data;
- output data;
- statuses;
- business rules;
- matching priority;
- validation algorithms;
- manual validation rules;
- automatic processing rules;
- UI expectations;
- security expectations;
- audit expectations;
- minimal data model;
- end-to-end flow;
- end-to-end scenarios;
- suggested APIs;
- NFR.

## Preserve

Preserve all acceptance criteria.

Do not collapse or remove user stories unless the user asks for consolidation.

Each acceptance criterion must be traceable to a generated specification or test.
